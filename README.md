## what it does

SKZ Focus is a productivity app built around the eight members of Stray Kids. pick your member, set your daily goal, and let them hold you accountable while you work.

- **60-minute focus timer** with a circular progress ring
- **10-minute break timer** that kicks in automatically
- **daily goal system** — set 1–8 sessions, watch the checklist fill up
- **task list** — add missions, pick one to focus on, check them off
- **session notes** — jot things down mid-session, auto-saved
- **member reactions** — each member has their own quotes for every timer state
- **day streak tracking** — builds if you hit your goal, resets if you skip
- **sound notifications** — soft chimes when sessions end (toggleable)
- **reward overlay** — member-specific message when you complete your daily goal

everything saves automatically so your tasks, notes, streak, and stats are always there when you come back.

## how to use

1. open the site
2. pick a member — changes the color theme and quotes
3. set your daily session goal (default: 4 sessions = 4 hrs)
4. add your tasks for the day
5. hit focus on the task you're starting
6. start the timer
7. work. the member will judge you accordingly.
